# Независимый пилот — инструкция координатору

Статус на 09.10.2026: участники и независимые эксперты не привлечены. Ни одна независимая оценка не заявляется. Автоматические проверки не заменяют этот эксперимент.

## Подготовка

После установки зависимостей выполнить `node scripts/pilot.cjs prepare outputs/pilot`. Повторная подготовка в той же папке запрещена, чтобы не заменить варианты после сбора ответов.

Получатся 18 HTML-форм: два варианта для каждой из девяти пар специализация/грейд. Роль и заявленный уровень соответствуют идентификатору участника P01–P09. Это слоты, а не реальные участники. При необходимости подготовьте дополнительный набор в новой папке и анализируйте его отдельно.

Координатор хранит `manifest-private.json` с эталонами отдельно. Участнику выдаются только два его HTML-файла из `participants/`. Формы работают при открытии локального файла и ничего не отправляют на сервер. Ключи ответов в них отсутствуют. Исходный код продукта содержит банк задач, поэтому участники не должны изучать его до эксперимента.

## Проведение

1. Получить добровольное согласие участника. Использовать только P01–P09, не собирать ФИО, дату рождения, почту или данные работодателя.
2. Эксперт независимо оценивает уровень по интервью/портфолио до теста, не видя результатов платформы. Заполнить `expert-grades.csv`: participantId, role, expertGrade (Junior/Middle/Senior), expertId, notes. Обе оценки разных экспертов при наличии сохраняются отдельно; текущий инструмент принимает одну согласованную оценку на участника.
3. Случайно выбрать порядок A/B, одинаковые условия, до 45 минут на форму. Не показывать правильные ответы между вариантами. Не разрешать внешнюю помощь; если она была, участник отмечает это в форме.
4. Участник сохраняет файл ответов кнопкой в конце. Координатор помещает оба JSON в `submissions/`. Файлы с помощью или превышением 45 минут исключаются из расчёта.
5. Для подбора эксперт изучает `ranking-dataset.json` и заполняет `relevance-labels.csv`: 0 — нерелевантен, 1 — частично релевантен, 2 — релевантен. Не показывать эксперту баллы алгоритма. Профили в этом наборе синтетические: даже независимая разметка не делает их реальными кандидатами.
6. Выполнить `node scripts/pilot.cjs analyze outputs/pilot`. Результат — `pilot-results.json`.

## Что рассчитывается

Результат каждой формы пересчитывается серверным модулем; клиентские баллы не принимаются. Согласование с экспертом означает, что прохождение заявленного уровня соответствует независимому уровню не ниже заявленного. Провал теста не присваивает человеку более низкий грейд.

Для участников с двумя формами считаются совпадение решения «прошёл/не прошёл» и средняя абсолютная разница баллов. Это описательная проверка повторяемости на малой выборке, не доказательство равносложности.

Для полностью размеченных потребностей считаются Precision@1, Precision@5 с фиксированным знаменателем 5, доля релевантных среди доступных результатов и nDCG@5. Сравнение выполняется с базовой сортировкой по совпадению стека в той же категории. Запросы с менее чем пятью кандидатами отмечаются отдельно. Неизвестные оценки не превращаются в нули; неполные запросы не включаются в расчёт.

## Ограничения

Пилот на 3–9 участниках разведочный. Для проверки надёжности, сложности отдельных заданий, дискриминативности и доверительных интервалов нужна существенно большая выборка по протоколу validation-protocol.md. Пороги нельзя подбирать по тем же людям, на которых заявляется итоговая точность. Результаты с искусственными правильными ответами пригодны только для проверки инструмента и не включаются в независимую валидацию.
