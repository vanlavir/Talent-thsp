# Готовность к защите: техническое усиление 0.4

Реализовано: транзакционное завершение теста, условные переходы приглашений, автоматическая отметка просмотра и обновление статусов, защита от устаревших ответов, прикладные задачи версии 3, рубрика и обратная связь работодателя, прозрачный индекс, управление видимостью и публичный предпросмотр, страницы выдачи, расширенные схемы API.

Доказательства: validation-results.json — серверные проверки и 900 генераций теста; http-validation-results.json — реальный локальный Worker; browser-validation-results.json — два кабинета в браузере; load-validation-results.json — 100 запросов с параллелизмом 10 на 1000 профилях; ranking-benchmark.json — 12 запросов, 1000 синтетических профилей, сравнение со стековым baseline.

Разметка ранжирования авторская: учитывает категорию и перекрытие стека. Она близка к правилам алгоритма и не заменяет независимую оценку работодателем. Средний nDCG@5 1.0 против 0.947 отражает только этот эксперимент. Повторы профилей увеличивают объём, но не разнообразие реальных людей. Локальный p95 около 749 мс не является обещанием скорости хостинга.

Показывать на защите: потребность → объяснимая подборка → профиль без контакта → приглашение с зарплатой и заданием → решение → оценка и комментарий → принятие → контакт. Во втором окне показать обновление статуса без ручной перезагрузки. Продемонстрировать скрытие образования и портфолио через публичный предпросмотр.

Нельзя заявлять: экспертную сертификацию грейдов, обучение ML, реальный импорт ФСП, полноценную защиту от списывания, промышленный SLA или завершённое юридическое соответствие. Реальный реестр недоступен по ТЗ; это допустимое ограничение, достижения демо-профилей синтетические.

Осталось с участием команды: независимый пилот (комплект версии 3 подготовлен отдельно), окончательная презентация, проверка публичного сценария с реальной почтой, утверждение политики данных и размещения для продуктивного запуска. Опциональное дальнейшее масштабирование: SQL-предфильтрация вместо загрузки всех профилей; ATS и реестр по настоящим контрактам.
