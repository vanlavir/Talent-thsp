# Протокол экспертной валидации (план пилота, не выполненный эксперимент)

1. Собрать независимых экспертов по Backend, Frontend и Data Science. Для каждой задачи два эксперта независимо оценивают однозначность условия, корректность эталона, компетенцию, ожидаемый грейд и время решения; расхождения согласуются третьим экспертом. Задачи с двусмысленностью исключить.
2. Для каждой роли набрать участников трёх уровней. Предварительный грейд устанавливают эксперты по интервью и портфолио, не видя результата платформы. Целевой пилот — минимум 20 участников на каждую пару роль/грейд (180 всего); меньшая выборка помечается как разведочная.
3. Каждый участник решает две независимые формы. Порядок форм случайный, условия одинаковые, без показа правильных ответов между формами. Фиксировать время, правильность, внешнюю помощь, технические сбои. Участие добровольное; использовать обезличенные идентификаторы.
4. Измерять точность согласования с экспертами и матрицу ошибок, weighted kappa, сложность каждой задачи (долю верных), дискриминативность и разницу результатов двух форм. Показать доверительные интервалы. Пороги 70/80/87 сейчас предварительные; менять их только по отдельной калибровочной выборке, проверить на отложенной.
5. Для подбора собрать не менее 30 независимых потребностей и 100 обезличенных профилей. Два эксперта размечают релевантность 0–2 по потребности, без просмотра индекса платформы. На фиксированной тестовой выборке сравнить платформу с базовой сортировкой по стеку; считать Precision@1, Precision@5 с одинаковым знаменателем и nDCG@5. Запросы с менее 5 доступными кандидатами показывать отдельно.
6. Опубликовать анонимный датасет, правило разбиения, версии алгоритма и банка, расчёты метрик, ограничения и неудачные случаи. Не заменять результаты мнением команды.

Форма фиксации задачи: taskId, role, grade, expert1, expert2, ambiguity, referenceCorrect, expectedMinutes, decision. Форма ответа: anonymousParticipantId, expertGrade, role, formId, taskId, correct, seconds, assistance, error. Никакие результаты этого пилота на 08.10.2026 не заявляются.
