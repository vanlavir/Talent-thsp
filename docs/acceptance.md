# Приёмка MVP — 09.10.2026

## Выполнено

1. Серверные модули с SQLite в памяти: 39 проверок, включая настоящую регистрацию через API, bcrypt, вход/выход, сохранение образования, опрос, 15 задач, категорию, приглашение, решение, общие статусы и раскрытие контакта только после принятия. Почтовый транспорт заменён заглушкой. Результаты: validation-results.json.
2. Чистая копия исходников в отдельной папке диска D: установлен npm 10, выполнены npm run install:ci и npm run build без старых node_modules и локального execution-profile. Обе SQL-миграции применены к новой локальной D1. Собранный Worker запущен через npm start.
3. На собранном Worker по HTTP прошли 20 операций с двумя новыми аккаунтами: профиль, образование, портфолио, опрос, тест, поиск категории, приглашение с зарплатой и заданием, решение, принятие и раскрытие контакта. Повторная сдача попытки отклонена. OpenAPI и документация доступны. Результаты: http-validation-results.json.
4. Пользователь сообщил об успешном получении кода на опубликованном сайте. Это отдельное сообщение пользователя, не автоматическая проверка production-почты. Локальные тесты не отправляют настоящих писем.

В автоматических сценариях правильные ответы берутся из изолированной тестовой базы. Поэтому эти результаты доказывают работу цепочки, но не профессиональный уровень человека.

## Браузерная проверка

На отдельном headless Edge с двумя независимыми контекстами пройден полный путь через интерфейс: регистрация кандидата, заполнение профиля, опрос, технический тест, присвоение категории; регистрация работодателя, сохранение компании, просмотр скрытого контакта, приглашение с зарплатой и собственным заданием; решение кандидата, принятие предложения, просмотр решения и контакта работодателем.

Сохранены шесть снимков в docs/screenshots и отчёт browser-validation-results.json. Трассы тестовых браузеров остаются локально, поскольку содержат сессионные данные. Это UI-проверка на синтетических аккаунтах с автоматическими ответами, не независимый пользовательский пилот. Почта на локальном сервисе не включалась.

## Независимая оценка качества

Подготовлен исполняемый пилот: 18 форм без эталонов в участнических файлах, таблицы независимых оценок, расчёт метрик и базовое сравнение подбора. Подробности: pilot-guide.md. Автоматический тест инструмента проверяет, что пустые данные не создают фиктивную экспертную точность. Реальных участников и экспертов пока нет; статус пилота — ожидается сбор данных.

## Что ещё требует человека

- Независимый пилот и экспертная калибровка грейдов.
- Проверка установки на другой операционной системе: чистый запуск выполнен на Windows, не заявляется проверка Linux/macOS.
- Финальная проверка публичной ссылки и доступности репозитория из аккаунта жюри.
- Презентация: отложена по запросу команды.

Автоматические тесты работают с синтетическими аккаунтами и отдельной базой; production-аккаунты не изменяются.
