# ФСП · Talent

MVP платформы обратного найма ИТ-специалистов. Кандидат подтверждает грейд и публикует профиль, работодатель ищет подходящую категорию и отправляет предложение с зарплатой и необязательным заданием.

Сайт: https://fsp-talent-lct.ambergleam8.chatgpt.site/

Исходники команды: https://github.com/vanlavir/Talent-thsp

## Локальный запуск

Node.js >=22.13, npm 10. Из корня проекта:

```sh
npm run install:ci
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_flimsy_bushwacker.sql
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0001_small_mordo.sql
npm run dev
```

Миграции применять только к новой локальной БД. Адрес печатает сервер, обычно http://127.0.0.1:5173. Для собранного Worker: `npm start`. Собственная регистрация на главной странице, ChatGPT-вход не требуется. Данные сохраняются в `.wrangler/state`.

## Проверка

```sh
node --max-old-space-size=128 scripts/validate-priority.cjs
node scripts/check-mailru.cjs
node scripts/check-pilot.cjs
```

39 условий серверного сценария, включая регистрацию, авторизацию и раскрытие контактов после принятия. Дополнительно проверен чистый запуск и 20 HTTP-операций на собранном Worker — см. docs/acceptance.md. Реальные серверные модули проверяются с SQLite в памяти и заменённым почтовым транспортом; production-данные не затрагиваются, письма не отправляются. Генерируются 900 форм, проверяются грейд, доступ к приглашениям, решения и email. Отчёт сохраняется в docs/validation-results.json. Это проверка механики, не экспертная валидация квалификации.

## Демонстрация

1. Зарегистрировать кандидата, выбрать отрасль и софт-скиллы, сохранить профиль и согласие на публикацию, добавить проекты в разделе «Портфолио».
2. Пройти обязательный опрос по отрасли, специализации и рабочим задачам, затем 15 задач выбранного грейда (10 ситуационных и 5 числовых); пороги 70/80/87%, не менее 3 практических задач. При успехе профиль доступен работодателям.
3. Создать отдельный аккаунт работодателя, заполнить компанию, найти профиль по категории и стеку, посмотреть портфолио.
4. Отправить предложение с зарплатой и заданием из каталога либо собственным условием.
5. Кандидат отправляет текст решения и ссылку, принимает предложение; работодатель видит решение и контакт.

## Почта и ограничения

Поддерживаются Mail.ru SMTP и Resend. Mail.ru: MAIL_PROVIDER=mailru, MAILRU_USER=talent-thsp@mail.ru, секрет MAILRU_PASSWORD — отдельный пароль приложения только для отправки. Собственный домен не нужен. До проверки отправки MAILRU_ENABLED=false; после проверки — true. Изменения переменных требуют публикации версии. Секреты не хранить в исходниках. Подробнее — в технической документации.

Достижения ФСП и восемь предустановленных профилей — синтетические. Реальный API реестра не подключён. Грейды требуют независимой экспертной калибровки. Нет восстановления пароля и исполнения пользовательского кода. Презентация не входит в эту итерацию. Все ограничения перечислены в технической документации.
